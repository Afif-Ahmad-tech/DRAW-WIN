# Draw Win

A local draw-and-guess game for 2–10 players.

## Run locally

```sh
npm start
```

Open <http://127.0.0.1:3000> in two or more tabs in the same browser. Create a room in one tab, then join with its code in the others. The host starts the game after at least two players have joined.

Room state syncs between tabs in the same browser profile. Cross-device multiplayer is not implemented yet.
